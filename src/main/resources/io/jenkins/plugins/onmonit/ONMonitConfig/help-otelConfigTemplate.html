If empty, the default OTEL config template is loaded from the plugin resources. By setting a value this overrides the OTEL config template.

The template is a Thymeleaf TEXT template. Insert string values with [(${yaml.quote(name)})], which writes a double-quoted YAML string, for example value: [(${yaml.quote(jobName)})]. It escapes quotes, backslashes and control characters, and doubles $ so the collector does not expand it. Avoid [[${name}]] for string values: it HTML-escapes them, so ', " and & end up as &#39;, &quot; and &amp;.

Available variables: otlpEndpoint, serviceName, jobName, jobGroupName, JENKINS_URL, pageUrl, nePort (number) and env (build environment, e.g. env.BUILD_ID).

The headers from OTEL_EXPORTER_OTLP_HEADERS are available as otlpHeadersYaml, a ready-made headers: block to insert under the exporter with [(${otlpHeadersYaml})], and as otlpHeaders, a map of header names to decoded values. The otlpAuthHeaderBefore, otlpAuthHeader and otlpAuthHeaderAfter variables are deprecated. A template that uses otlpAuthHeader without otlpAuthHeaderBefore receives the value of the first header in it.
