If empty, the default OTEL config template is loaded from the plugin resources. By setting a value this overrides the OTEL config template.

The headers from OTEL_EXPORTER_OTLP_HEADERS are available as otlpHeadersYaml, a ready-made headers: block to insert under the exporter with [(${otlpHeadersYaml})], and as otlpHeaders, a map of header names to decoded values. The otlpAuthHeaderBefore, otlpAuthHeader and otlpAuthHeaderAfter variables are deprecated.
